# Tempo — AI Life OS

**Tempo** — персональная операционная система жизни с ИИ: финансы, календарь, задачи и питание в одном интерфейсе. Telegram Mini App + адаптивное веб-приложение.

Одно сообщение — и ИИ раскладывает всё по разделам:
> «Потратил 18 евро на обед, курица с рисом, завтра встреча в 15:00»

превращается в три записи: расход (финансы), приём пищи (питание) и событие (календарь) — с подтверждением перед сохранением.

## Возможности

- **AI-захват** — текст, голос или фото еды → структурированный JSON → строгая валидация → лист подтверждения с редактируемыми карточками. Ничего не сохраняется без вашего «Записать».
- **Ассистент** — чат, отвечающий только по вашим реальным данным. Не выдумывает цифры.
- **Финансы** — доходы/расходы, мультивалютность, бюджеты по категориям, диаграммы, поиск.
- **Календарь** — сетка месяца, повторы событий, напоминания.
- **Задачи** — приоритеты, повторяющиеся задачи, разделы «просрочено / сегодня / впереди».
- **Питание** — кольцо калорий, БЖУ, оценка блюд по тексту или фото, свои продукты.
- **Профиль** — настройки, выбор модели ИИ, персонализация ответов, виджеты главной, экспорт/импорт данных, политика конфиденциальности и условия.
- **Оплата** — тарифы и два способа: Telegram Stars (автоматически) и банковская карта через LiqPay (автоматически при настроенных ключах, иначе заявка с ручной активацией).

## AI Router (серверная архитектура)

Все запросы к ИИ идут через серверный роутер (`ai-router.mjs` + `/api/ai/chat` в `server.mjs`):

- **Ключ Gemini только на сервере** — из клиентского бандла ключ убран. Свой личный ключ (опционально) по-прежнему можно указать в Профиле.
- **Реестр моделей** — только модели, проверенные реальными запросами: Gemini 3.5 Flash Lite (Fast), Gemini 3.5 Flash (Balanced/Advanced). Нестабильные на момент проверки (3.6–3.8 Flash) отключены.
- **Автоматический фолбэк** — таймауты, 429/503 → следующая модель в цепочке, с честным уведомлением пользователю.
- **Стриминг** — ответы в чате приходят по SSE, с кнопкой «Стоп».
- **Два режима** — «Чат» (обычный разговор, без JSON) и «Действия» (структурированный вывод для создания записей с подтверждением).
- **Серверные лимиты** — 10/100/300 запросов в день (Free/Plus/Pro), сброс по часовому поясу пользователя, проверка на сервере, а не в интерфейсе.
- **Персонализация** — глубина, длина, тон, формат ответов и температура (Pro) сохраняются в профиле.

## Принципы

1. **ИИ не выдумывает данные.** Нет суммы, даты или продукта — ИИ спросит, а не придумает.
2. **Подтверждение перед записью.** Любое действие видно и редактируемо до сохранения.
3. **Никаких фейковых функций.** Если сервер оплаты недоступен — интерфейс честно об этом говорит.
4. **Права проверяет сервер.** Тариф, лимиты ИИ и доступ к моделям определяются на сервере, а не в браузере.

## Технологии

React 19 · TypeScript · Vite · Tailwind CSS · Zustand · Telegram WebApp SDK · Node.js-сервер без зависимостей (server.mjs + ai-router.mjs) · Gemini API.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173 (AI-роутер: PORT=3000 node server.mjs)
npm run build      # продакшн-сборка в dist/
```

Для сервера скопируйте `.env.example` → `.env` и заполните переменные (BOT_TOKEN, ADMIN_PASS, WEBHOOK_SECRET, GEMINI_API_KEY). Без GEMINI_API_KEY сервер использует встроенный пилотный ключ — замените его своим при первом деплое.

## Данные и приватность

Данные хранятся локально (localStorage) и зеркалируются в Telegram CloudStorage (если доступен). При создании аккаунта снимок данных дублируется на сервер для входа с других устройств. Для ответов ИИ отправляется только компактный контекст (недавние операции, задачи на сегодня, итоги питания) и ваш текст — не вся база. Экспорт/импорт JSON и полное удаление аккаунта — в Профиле; политика конфиденциальности и условия — в Профиле (иконки внизу).

**https://tempo-lifeos.pplx.app** — фронтенд + серверная часть (аккаунты, синхронизация данных, оплата Telegram Stars, админ-панель, рефералы) работает на этом адресе. Сервер `server.mjs` запускается хостингом с переменными `BOT_TOKEN`, `ADMIN_PASS`, `WEBHOOK_SECRET` (см. docs/ACCOUNTS-ADMIN.md).

```bash
BOT_TOKEN=<токен бота> ADMIN_PASS=<пароль админа> WEBHOOK_SECRET=<случайная строка> PORT=3000 node server.mjs
# webhook: https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<адрес>/api/telegram-webhook&secret_token=<WEBHOOK_SECRET>
```

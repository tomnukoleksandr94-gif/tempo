# Аккаунты, админ-панель, платежи

Дата: 13 ноября 2026.

## Аккаунты (вход на любом сайте)

- Регистрация/вход: логин + пароль (мин. 6 символов), пароли хешируются scrypt с солью — на сервере.
- Сессия — токен (30 дней), хранится в localStorage устройства.
- Синхронизация данных: «Сохранить в облако» / «Загрузить из облака» в Профиле → Аккаунт (JSON-снимок данных, до 2 МБ).
- В Telegram Mini App аккаунт связывается автоматически через верифицированный initData (пользователь Telegram, чей username совпадает с привязанным, получает свои данные).

## Админ-панель

- Доступна в Профиле после входа владельцем: **логин `Mister`, пароль задаётся переменной `ADMIN_PASS`** (по умолчанию выдан владельцем).
- Владелец в Telegram: **@neggshka** — его initData автоматически резолвится в админ-аккаунт.
- Возможности: сводка (аккаунты/платящие/платежи/собрано Stars), список пользователей с историей платежей и рефералами, выдача подписки вручную (Plus/Pro на месяц/год, например награда за рефералов), отзыв подписки.
- Все админ-запросы проверяются на сервере (роль из сессии, пароль вне клиента).

## Платежи (Telegram Stars)

- Клиент запрашивает ссылку-инвойс у сервера → `openInvoice` в Telegram → webhook `successful_payment` активирует подписку. Клиент никогда не решает сам, «оплачено» или нет.
- Идемпотентность по `telegram_payment_charge_id`; повторные webhook-уведомления не дублируют историю.
- Цены (Stars): Plus 250 XTR/мес, 2500 XTR/год; Pro 450 XTR/мес, 4500 XTR/год. В евро: 4.99/8.99 (год 49.90/89.90), со скидкой запуска −3 €/мес до 01.12.2026 → 1.99/5.99.
- Если сервер недоступен, в UI честно написано «Платежный сервер недоступен» — никаких фиктивных активаций.

## Рефералы

- Ссылка `https://t.me/Tempo00Bot?start=ref_<id>`; сервер считает приглашённых и оплативших (защита: свой код использовать нельзя, повторный /start не считается).
- Награды (3 оплативших → месяц Plus; 5 → месяц Pro) выдаёт владелец через админ-панель или автоматически после интеграции с биллингом.

## Запуск сервера

```bash
BOT_TOKEN=<токен бота> ADMIN_PASS=<пароль админа> WEBHOOK_SECRET=<случайная строка> PORT=3000 node server.mjs
# webhook (обязательно с secret_token — без него сервер отклонит запросы):
# https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<адрес>/api/telegram-webhook&secret_token=<WEBHOOK_SECRET>
```

Текущий продакшн: **https://tempo-ai-life-os.pplx.app** (сервер проксируется по пути `/port/3000/`).

Безопасность сервера: webhook принимает только запросы с заголовком `X-Telegram-Bot-Api-Secret-Token` = `WEBHOOK_SECRET`; без `ADMIN_PASS` админ-аккаунт не создаётся; вход/регистрация ограничены 5 попытками в минуту с IP; токен сессии передаётся в заголовке `Authorization: Bearer`.

Хранилище — JSON-файл `data.json` (для пилота; при масштабировании заменить на БД). Внимание: при деплое не включайте локальный `data.json` в сборку — он может перезаписать продакшн-данные.

# Tempo — оценка проекта и план обновления (13 ноября 2026)

## 1. Оценка текущего проекта

**Сильные стороны (сохраняем):**
- Рабочий AI-конвейер: текст/голос/фото → Gemini → строгая валидация → подтверждение → запись (протестирован сквозными тестами Playwright, 8/8 PASS).
- Чистая архитектура: Zustand-стор + safeStorage (localStorage + Telegram CloudStorage), без бэкенда как единой точки отказа.
- i18n RU/EN, дедупликация записей, экспорт/импорт JSON.
- Дизайн-система на CSS-переменных, iOS-стиль, «островок» с часами.

**Проблемы (найдены при осмотре):**
1. **Telegram Desktop/Web: мини-приложение не открывается** — опубликованный сайт отдаёт `X-Frame-Options: DENY` + `frame-ancestors 'none'`, а Telegram Desktop/Web загружают мини-приложения в iframe → пустой экран. На мобильных (нативный webview) работает.
2. **Нет светлой темы** — только тёмная; в коде захардкожены `bg-white/*`, `border-white/*`, которые нельзя переопределить.
3. **Перегруженная навигация** — 7 вкладок в таб-баре (Главная, AI, Финансы, Календарь, Задачи, Еда, Профиль) на ширине 390px читаются на пределе.
4. **Главная перегружена** — много карточек, дублирующая информация («Расходы за неделю» повторяет заголовок секции), большие пустоты.
5. **Тарифы не реализованы** — «оплата подключается», нет лимитов по планам, архитектуры оплаты и серверной верификации.
6. **Нет реферальной системы.**
7. **Финансы** — нет сводного баланса и разбивки доходов по категориям; AI-отчётов нет.
8. Лимит ИИ фиксированный (20/день) вместо план-зависимого.

## 2. Предлагаемый редизайн

- **Дизайн-направление:** минимализм, премиум, чёрный/белый/серый + сдержанный фиолетовый акцент (#8E7BEF). Тёмная и светлая темы (авто по Telegram + ручной выбор). Меньше карточек, строгая типографика Manrope, консистентные отступы, сдержанные анимации.
- **Навигация — 5 разделов:** Главная, AI, Финансы, Планирование, Профиль. Календарь, задачи и питание — подвкладки внутри «Планирования».
- **Главная:** приветствие + дата → AI-ввод → компактная строка метрик (баланс, расход за день, калории, задачи) → задачи на сегодня → ближайшие события → мини-обзор питания → инсайт дня.

## 3. Функции для добавления

- Подписки: Free / Plus €4.99 / Pro €8.99 (месяц), годовые со скидкой; **скидка на запуск −3 €/мес до 1 декабря 2026** (цены 1.99/5.99, с явной пометкой). Лимиты AI: 10/100/300 действий в день. Экран тарифов, сравнение, апгрейд, история платежей, отмена, дата окончания.
- Рефералы: ссылка t.me/Tempo00Bot?start=ref_<id>, прогресс (1 друг → прогресс, 3 платящих → месяц Plus, 5 платящих → триал Pro), дашборд.
- Финансы: сводный баланс, разбивка доходов по категориям, AI-отчёт по тратам.

## 4. Изменения данных

- Клиентский стор: `settings.theme` ('auto'|'dark'|'light'), `subscription { plan, period, expiresAt, status, history[] }`, `referralId`, счётчик AI по плану.
- Новый сервер (JSON-хранилище, без внешней БД): пользователи (подписки, платежи), рефералы, верификация Telegram initData (HMAC, серверный ключ бота), создание Telegram Stars-инвойсов, вебхук successful_payment → активация подписки. Схема Supabase из docs/SCHEMA.sql остаётся путём миграции.
- Платежи: только Telegram Stars (XTR) — внутри Telegram, без симуляции. Статусы берутся с сервера, а не выдумываются клиентом.
